# 财搭子研究看板 · DSH 插件

把三个研究问题放进 DeepSeek Harness：**存储涨价能否兑现利润、AI 基建能否赚回投入、PCB／CCL 规格升级能否变成订单**。

这是可安装的首个预览版。看板通过个人财搭子 API Key 获取行情与研究线索；继续研究时，将看板问题和情景参数带入 DSH 原生会话。

## 安装

需要 Node.js **24.9.0+**、DeepSeek Harness **0.2.2-rc.2**。已实测该版本 Web 界面；不宣称支持其他版本或 Desktop 内置通信。

```sh
npm install -g @deepseek-ai/dsh@0.2.2-rc.2
dsh plugin --profile web add https://github.com/markthc/dsh-caidazi-boards/releases/download/v0.1.0/caidazi-dsh-boards-0.1.0.tgz
dsh web
```

也可下载 Release 中的 `.tgz`，执行 `dsh plugin --profile web add ./caidazi-dsh-boards-0.1.0.tgz`。包已预编译，安装不用执行本插件的构建脚本。

1. 打开 DSH 左侧的 **财搭子看板**。
2. 点击 **连接财搭子**，粘贴财搭子 App → 大发 → Skills 页面获得的 API Key。插件会实际请求行情验证，成功后保存到 DSH 凭据区。也支持宿主进程已有的 `CAIDAZI_API_KEY`。
3. 三张看板首次打开时自动加载；之后点击 **刷新数据** 更新。没有后台轮询或定时任务。
4. **继续研究** 或单项研究入口打开 DSH 会话草稿，已带入问题与参数；检查后发送。需要 DSH 自身已配置可用的模型。回到看板保留本次页面内的数据、选项与参数；重新加载浏览器后重新读取。

## 三张看板

| 看板 | 交付 |
| --- | --- |
| 存储产业跟踪 | 兆易创新分时、美光报价、可展示的存储资讯；产品价格→供给→利润兑现三条研究路径 |
| AI 基建 · 成本与回报 | 中际旭创分时、微软和英伟达报价；投入资本/回报要求/净利率可调，立即计算收入门槛与敏感性曲线 |
| PCB／CCL · 升级兑现 | 生益科技分时、沪电股份和深南电路报价；材料认证→产能交付→盈利质量三条研究路径 |

- **数值层**：`get_real_time_record`、`get_a_share_history_1m_price`。只显示实际返回的报价与最近两个可用交易日的分钟收盘价；补点/未完成点留空。图表写明币种、口径、日期与时间。
- **资料层**：`investment_search_pro`。仅展示 `authorized` / `citation_only` 的标题、出处与原文链接；过滤无关内容、过期资料、未来日期和原文日期冲突。不转发新闻全文或机构研报图片。
- **研究层**：注册官方 `@caidazi/mcp@0.2.10` 内的 8 个 Skills 和 MCP 工具。DSH 会话使用用户自己的模型继续分析。看板不把价格上涨自动转成投资结论，也不将缺资料判成检查通过。
- **情景层**：AI 基建默认 `100亿元 × 15% ÷ 24% = 62.5亿元/年`，全部是可改假设，不是某家公司的披露或预测。

## 连接和边界

Key 只从浏览器提交给本地 DSH，再由宿主传给财搭子官方 MCP bridge；不放入 URL、浏览器持久化、聊天或分享文件。接口沿用 DSH 的浏览器认证、Host/Origin 检查与 owner 权限。DSH 本地凭据文件不等同于操作系统级密钥隔离。

看板本身只读公共数据；不会读取持仓、修改自选、创建监控或执行交易。配套官方 Skills/MCP 包含个人资产等工具，只有用户后续提出相关请求时才应使用。Key 的账户权益、额度与撤销由财搭子服务端决定；本插件不新增收费或承诺数据 SLA。

当前行情可能延迟，报价旁展示的是接口交易时间；美股接口未标时区时如实注明。历史行情有时返回非连续交易日，以实际日期为准。本轮存储搜索存在日期/权限不满足展示条件的结果，页面可能无研究线索；这不等于市场没有新闻。

**尚未接入**：DRAM/NAND 连续产品价格、企业季度 CAPEX/利润/现金流结构化序列、云端持续监控、收藏/fork 同步、注册和发 Key 页面。这些需要财搭子补充数据或产品接口。完整基本面结论仍需在会话中完成，不能将本预览版当成全部研究数据已自动化。

## 开发

```sh
npm ci
npm test
npm run build
npm pack
```

源文件 `src/host.js` 负责原生接入及鉴权，`src/data.js` 负责三个固定工具的数据解释与权限筛选，`src/client.jsx` 为主面板。不存在单独的 Web 后端、数据库或新增框架。

代码采用 MIT。数据与第三方服务遵循各自许可和账户条款。发布包不含任何用户 Key、持仓、测试响应或机构材料。
